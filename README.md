# Matthew Goodman

Software engineer and quantitative researcher working across **aerospace simulation, autonomous systems, scientific computing, semiconductor research, and market microstructure**.

Currently completing a **Master of Financial Engineering at UCLA Anderson** after studying **Computer Science and Economics at Columbia University**. I like problems where software, numerical models and physical systems meet.

## Featured Work

### Aerospace / GNC / Simulation
**[Aerospace 6-DoF / Orbital Simulation](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/aerospace-6dof)**  
C++/Python simulation and verification stack spanning rigid-body dynamics, astrodynamics, orbital propagation, conjunction analysis and GNC.

### Robotics / Autonomy
**[Jetson Autonomy Simulator](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/jetson-autonomy-sim)**  
C++ autonomy stack bridging desktop simulation and NVIDIA Jetson deployment with estimation, planning, control, V4L2/DMA-BUF and CUDA/TensorRT boundaries.

**[LeRobot MicroFactory](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/lerobot-microfactory)**  
Simulation-first autonomous robot cell with deterministic safety, verification, recovery, randomized evaluation and robot-learning integration boundaries.

### Semiconductors / Physical AI
**[BOM-X — AI / Semiconductor Research Engine](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/bom-x-research)**  
Interactive research terminal connecting AI/software demand to compute, memory, foundry/packaging, networking, power, WFE/test and supplier expectations.

### Scientific Computing & Remote Sensing
**[HyTES Cal/Val Model](https://github.com/MatthewDavidGoodman/HyTES-Cal-Val-Model)**  
Physics-first calibration and validation workflow for thermal remote-sensing observations with explicit units, quality control and out-of-sample validation.

### Quantitative Trading & Market Microstructure
**[Opening Trading Boost](https://github.com/MatthewDavidGoodman/opening-trading-boost)**  
Offline research system using MBP-10 level-2 order-book data to rank opening setups, model execution choices and compare selective versus extended intraday use.
