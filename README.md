# Matthew Goodman

Software engineer and quantitative researcher working across **scientific computing, autonomous systems, market microstructure, semiconductors, and space systems**.

Currently completing a **Master of Financial Engineering at UCLA Anderson** after studying **Computer Science and Economics at Columbia University**. My recent work combines software, numerical modeling, machine learning, and physical systems.

## Featured Work

### Aerospace / GNC / Simulation
**[Aerospace 6-DoF / Orbital Simulation](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/aerospace-6dof)**  
C++/Python simulation and verification stack spanning rigid-body dynamics, astrodynamics, orbital propagation, conjunction analysis, and ArduPilot SITL integration.

### Robotics / Autonomy
**[LeRobot MicroFactory](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/lerobot-microfactory)**  
Simulation-first autonomous robot-cell project with policy, deterministic safety, verification, recovery, randomized evaluation, and LeRobot integration boundaries.

**[Jetson Autonomy Simulator](https://github.com/MatthewDavidGoodman/Portfolio/tree/main/projects/jetson-autonomy-sim)**  
C++ autonomy stack bridging desktop simulation and NVIDIA Jetson deployment, with estimation, planning, control, V4L2/DMA-BUF, CUDA/TensorRT, and embedded-Linux scaffolding.

### Scientific Computing & Remote Sensing
**[HyTES Cal/Val Model](https://github.com/MatthewDavidGoodman/HyTES-Cal-Val-Model)**  
Physics-first calibration and validation workflow for thermal remote-sensing observations, with explicit units, quality control, uncertainty handling, and out-of-sample validation.

### Quantitative Trading & Market Microstructure
**[Opening Trading Boost](https://github.com/MatthewDavidGoodman/opening-trading-boost)**  
Offline research system using MBP-10 level-2 order-book data to rank opening setups, model execution choices, and compare selective versus extended intraday use.
